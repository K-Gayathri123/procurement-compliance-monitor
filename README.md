# Procurement Compliance Monitoring System

A full-stack application for procurement compliance monitoring.

## Tech Stack

- Backend: Java 21, Spring Boot, Maven
- Frontend: React, Vite
- Database: SQLite
- Authentication: JWT

## Features

- User authentication and role management
- Supplier management
- Contract management
- Purchase order CSV ingestion
- Compliance evaluation
- Exception detection
- Review workflows
- Procurement analytics

## Project Structure

- backend/ - Spring Boot application
- frontend/ - React application

## Backend Setup

1. Install Java 21.
2. Configure required environment variables.
3. Run the backend using Maven.

## Frontend Setup

1. Install Node.js.
2. Run npm ci.
3. Run npm run dev.
